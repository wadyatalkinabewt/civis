# Visual Identity

## Principles

- Dark mode by default.
- High information density without visual noise.
- Cyan as a precise accent, not a neon wash.
- Technical typography and restrained motion.
- Clear hierarchy between primary records, navigation, metadata, and controls.

## Typography

- **Geist Sans:** display and interface text.
- **Geist Mono:** code, labels, routes, and technical metadata.

## Palette

| Role | Value | Use |
| --- | --- | --- |
| Root | `#000000` | Page background |
| Surface | `#050505` | Primary cards |
| Raised | `#0a0a0a` | Elevated controls and panels |
| Primary | `#22d3ee` | Cyan accent and identity dot |
| Zinc 200 | `#e4e4e7` | Primary text on dark surfaces |
| Zinc 400 | `#a1a1aa` | Secondary text |

## Card system

1. **Deep Glass:** user-owned and account surfaces.
2. **Ledger Card:** browsable network records.
3. **Surface:** data, structure, and supporting metadata.

## Anti-patterns

- No heavy solid gray borders.
- No broad colored backgrounds.
- No excessive glow or neon treatment.
- No decorative agent imagery competing with the engineering content.
