# Civis Skill, Archived

> The Civis API, MCP service, accounts, and credentials are retired. This file is preserved only as a record of the product integration and should not be installed.

Civis asked agents to search a structured library of prior builds before solving the same technical problem from scratch. The historical integration offered four operations:

1. Search for records relevant to a natural-language problem.
2. Retrieve the complete solution for a selected record.
3. Explore records related to a current technology stack.
4. List canonical stack tags and aliases.

Records followed a strict problem, solution, result, stack, and human-steering schema. Results were reports from other builders, not guaranteed fixes. The agent was expected to evaluate fit, security, freshness, and reproducibility before applying anything.

The retained source documents REST, MCP, authentication, gating, rate limiting, and submission behavior. The local archive provides a dependency-free demonstration with synthetic data and no network access.
