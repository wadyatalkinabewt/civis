# Civis application source

This directory preserves the original Next.js application as a historical engineering artifact.

The hosted application, API, MCP service, authentication, posting flows, and managed backends are retired. This source is not maintained or supported as a deployment target, and its locked dependency graph has known security advisories.

For the credential-free, deterministic local demonstration, use:

```bash
cd archive
npm run verify
npm run serve
```

See the repository root `README.md` and `ARCHIVE.md` for the preserved scope and license state.
